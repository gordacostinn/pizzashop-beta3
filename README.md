# 🍕 PizzaShop Beta 3

PizzaShop is a web application built to simplify the daily operation of a local pizzeria.

Instead of being just another practice project, PizzaShop was created to solve a real workflow problem by helping manage orders, inventory, deliveries, payments, and daily sales in a simple and intuitive interface.

## ✨ Features

### 🍕 Product Management

Pizza catalog with multiple varieties

Pizza promotions

Empanada sales

Business orders

Custom orders

### 📦 Inventory Management

Real-time pizza dough tracking

Real-time empanada stock tracking

Manual stock adjustments

Automatic stock validation before confirming orders

### 🛒 Order Management

Live order preview

Automatic subtotal and total calculation

Order cancellation

Order confirmation

Complete order history

Remove confirmed orders

### 🚚 Delivery System

Pickup or delivery

Shipping cost management

Driver assignment

Delivery statistics by driver

### 💳 Payment Methods

Cash

Bank Transfer

Hybrid Payment (Cash + Transfer)

### 📊 Daily Summary

Total income

Cash income

Transfer income

Pizzas sold

Empanadas sold

Remaining inventory

Delivery totals

Complete order history

### 🛠 Technologies

HTML5

CSS3

JavaScript (Vanilla)

LocalStorage

## 🚀 Running the project

Clone the repository:

git clone https://github.com/gordacostinn/pizzashop-beta3.git

index.html

## 🎯 Project Goals

The main objective of this project is to practice JavaScript by building software that solves a real business problem.

Throughout the project I focused on:

Writing modular JavaScript functions.

Managing application state with LocalStorage.

DOM manipulation.

Event handling.

Dynamic interfaces.

Inventory validation.

Order processing.

Responsive design.

## 📈 Current Status

PizzaShop is currently under active development.

Future updates will continue improving usability, performance, and adding new features based on real-world feedback.
